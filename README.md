# Linear-House-regression
Built a machine learning model using Linear Regression to predict median house prices based on features like location, income, housing age, and population.

Performed data cleaning, preprocessing, and exploratory data analysis (EDA) to identify key correlations and trends.

Implemented the model in Python using NumPy, Pandas, and scikit-learn, and evaluated performance using metrics like R² score and Mean Squared Error (MSE).

Gained hands-on experience in feature selection, model training, and result interpretation for real-world datasets.
